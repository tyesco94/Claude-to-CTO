## Process
1. Read the whole transcript. Extract 5–7 **distinct ideas**: a strong opinion, a story, a how-to, a stat/result, a mistake/lesson, a contrarian take.
2. Produce this package (Monday–Sunday):
   - **2 X/Twitter threads** (6–10 posts each). Post 1 is a hook that works alone; last post = takeaway + soft CTA.
   - **3 LinkedIn posts** (150–250 words). First line hooks, short paragraphs, end with a question.
   - **1 SEO blog post** (900–1,300 words): suggested title, meta description (≤155 chars), target keyword, H2/H3 structure, FAQ section.
   - **5 short-video hooks** (first 3 seconds, ≤15 words each) with the matching timestamp/quote from the transcript.
   - **Posting calendar** table: day, platform, piece.
3. Every piece must be traceable to something actually said in the transcript — no invented claims, numbers or stories.
4. Match the voice profile. Read each piece and remove anything that sounds generic or AI-written.
